Why thinking.tools

EU only, GDPR compliant
Requests are processed in EU datacenters by an EU company and never leave the EU. We act as your processor under Art. 28 GDPR and sign a data processing agreement with every customer.
Zero data retention, no IP leaks
Prompts and responses exist in memory only while the request runs. Nothing is stored, logged or used to train a model, so your code, documents and research stay yours.
Fast inference
Models run quantized to FP4 or FP8 and stream every token as it's generated, so answers start arriving right away.
Affordable pricing
Open models cost a fraction of the big closed ones, and on the shared API you pay only for the tokens you use.

Keep your OpenAI code.

Point any OpenAI SDK at our base URL, use your key and pick a model. Nothing else changes. 

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.thinking.tools/v1",
  apiKey: process.env.TT_API_KEY,
});

const res = await client.chat.completions.create({
  model: "glm-5.3",
  messages: [{ role: "user", content: "Hello" }],
});

console.log(res.choices[0].message.content);
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.thinking.tools/v1",
    api_key=os.environ["TT_API_KEY"],
)

res = client.chat.completions.create(
    model="glm-5.3",
    messages=[{"role": "user", "content": "Hello"}],
)

print(res.choices[0].message.content)
